# Sécurité

Pour signaler une vulnérabilité (page générée, chaîne de CI, dépendance), n'ouvrez pas d'issue publique : utilisez
« Report a vulnerability » dans l'onglet *Security* du dépôt GitHub. Vous recevrez une réponse sous une semaine.

Le site est statique : sans cookie, sans compte, sans traceur. Le dépôt ne contient ni secret ni clé d'API ; les
sources qui en demanderaient une passent par un secret de CI, nommé dans `catalogue/`.
