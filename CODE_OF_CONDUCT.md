# Code de conduite

Ce projet traite de sujets politiques : la rigueur et le respect y sont donc plus importants qu'ailleurs.

- Discutez des sources, des méthodes et des chiffres, pas des personnes.
- Pas d'insultes, de harcèlement, de discrimination, ni de propagande : les contributions militantes sans source sont
  refusées, quel que soit le bord.
- Pas de données personnelles de tiers, hors propos publics des personnalités politiques dans le cadre de leur
  campagne.
- Une critique du travail est bienvenue quand elle est vérifiable ; une erreur reconnue est corrigée ouvertement.

Les mainteneurs peuvent supprimer un commentaire ou une contribution qui contrevient à ces règles, et exclure son
auteur. Signalement : voir `SECURITY.md` pour le contact, ou les mentions légales du site.
